DEATH COMPASS 1.3 - APPLY UPDATE IN GITHUB

1. Keep your currently working mod JAR until the new one builds and launches.
2. Extract this ZIP.
3. Open your GitHub repo in github.dev (press period on its Code page).
4. Replace the existing files with ALL extracted contents (including src, .github,
   scripts, and the root Gradle files). Don't upload the ZIP as a single file.
5. Source Control > Commit & Push.
6. Open Actions > Build and Verify Death Compass; open the new run.
7. If green, download DeathCompass-VERIFIED-JAR from Artifacts, extract the ZIP,
   and install the non-sources JAR in Prism (remove old deathcompass JAR).
8. Test in a disposable world. Press grave (`) for Death Compass settings;
   press K for Secondary Keybinds, also available under Options > Controls.
9. Safety > Warning sounds & volume permits turning sounds off individually.

If red, copy the first error lines from the FAILED step in the GitHub Actions log.
Do not install the supplied 1.21.11 SecondaryKeybind JAR on 26.2.

LIMITATIONS:
- 26.2 compile and in-game behavior have NOT been tested in this environment.
- The secondary-keybind feature was rebuilt from observed behavior and 26.2 APIs,
  not copied byte-for-byte or with an exact pixel-for-pixel UI.
- Loaded client data cannot guarantee lava/gravel behavior or structure boundaries.
